19 / MATRIX
Expandable speaker notes

ประเด็นที่ควรขยาย
เมื่อลูกค้าถามต่อ

Traditional Pentest พอหรือไม่?
  • Traditional Pentest ยังจำเป็นสำหรับ Web, API, Authentication และ Authorization
  • AI เพิ่ม Behavior Layer เช่น adversarial input, model manipulation, data poisoning และ sensitive output
  • คำถามขาย: “การทดสอบปัจจุบันครอบคลุม AI-specific attack ตาม Control Objective หรือยัง?”
Continuous Monitoring ต้องเห็นอะไร?
  • Prompt / response / anomalous behavior และ security event
  • Model output, performance, data quality และ feedback เพื่อปรับปรุงต่อเนื่อง
  • ต้องเชื่อมกับ incident response และความสามารถหยุด/จำกัดระบบ
Human Oversight สำคัญอย่างไรกับ High-risk AI?
  • เมื่อ AI มีผลต่อ Underwriting, Pricing หรือ Claims ต้องออกแบบจุดที่มนุษย์ตรวจสอบหรือแทรกแซงได้
  • เป้าหมายไม่ใช่แค่ Security แต่รวม Fairness, Consumer Protection และการลด Unfair Treatment
Third-party AI ต้องเริ่มถามอะไร?
  • องค์กรอนุญาต Provider ใด และมี Use Case ใดบ้าง?
  • ข้อมูลประเภทใดส่งเข้าได้/ไม่ได้ และมี Enforcement จริงหรือไม่?
  • มี Log, Vendor Risk Assessment และวิธีรับมือ Incident หรือไม่?
